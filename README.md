# Go CLI To-Do List

## Description

This is a simple **command-line task management** application written in Go.  
It allows users to add tasks, list them, mark them as completed, and remove tasks from the list. Each task has a status indicating whether it is **pending** or **completed**.

---

## Features

- Add new tasks to the list  
- List all tasks with their status (`[Pending]` for pending, `[Completed]` for completed)  
- Mark tasks as completed  
- Remove tasks from the list  

---

## How to Run
1. Clone the repository:
```bash
git clone https://github.com/isaaczidany/to-do-list
```
2. Navigate to the project directory:
```bash
cd to-do-list
```
3. Compile and run the program:
```bash
go run todo.go
```
